# Where each company's own icon comes from

Only a company's OWN icon goes here (its app icon or its website's icon), never a piece cut from its logo: the owner's
rule, 24 Nov 2026. One `<logo>.png` per company, named like its logo (`apps/web/public/couriers/<logo>.webp`), then run
`python3 scripts/courier-logos-icon.py`. Taken from each company's own website on 24 Nov 2026.
